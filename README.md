# Personal Website 2026

Faris Siddiqi's personal site, built with Next.js.

## Run it

```
npm install
npm run dev
```

## Layout

- `app/` – the page (`Scene.tsx`), the zoom's geometry (`sceneMath.ts`), its styles (`globals.css`) and the site shell.
- `app/terminal/` – the terminal on the astronaut's chest. Edit `content.ts` to change the about text or projects.
- `public/scene/` – the optimized images the page loads.
- `layers/` – the original full-size artwork the images in `public/scene/` are made from.
